DINOv3 Pipeline & Fusion Components for UTAE

Forward processing: multi-modal satellite series → adapted ViT-S/16 → gated Stage-3 feature injection (UTAE omitted).
Raw Multi-Modal Time Series x(t) [B, T, C, H, W]
Satellite reflectance + weather + terrain + fire masks (T = 5 days, C = 40 channels, H×W pixels).
Temporal Flatten & Bilinear Scale (2.0×) [B·T, C, 2H, 2W]
flatten(0, 1) processes all days in parallel; scaled to match ViT patch grid (16×16).
Adapted Patch Embedding (Trainable) C → 384 dim
Conv2d(kernel=16, stride=16). Replicates RGB weights across C channels: W_new = (W_rgb.mean · 3/C).repeat(1, C, 1, 1).
Pretrained DINOv3 ViT-S/16 Backbone 12 Blocks, 6 Heads
• 1 [CLS] token + 4 Register tokens + N Patch tokens (N = H/8 × W/8) + 2D Axial RoPE.
• Warm-up (< 5 ep): ViT frozen, only patch embedding trains.
• Fine-tune (≥ 5 ep): Unfreeze last 4 blocks + norm (LR mult = 0.01).
Feature Extraction & Spatial Reshape (Layer 11) [B·T, 384, H/8, W/8]
Applies final LayerNorm; discards [CLS] and registers; un有機/flattens patch tokens to 2D grid.
DinoFusion Module (Trainable Adapter) d: 384 → 128 dim
• Proj: Conv 1×1 (384 → 128) + GroupNorm(4) + GELU → Bilinear resize to (H/8, W/8).
• Mix & Gate: out = c + gate · Conv3x3([c, proj(d)]) with learnable gate = 0.0 (zero-init).
Output Injected to UTAE Stage 3 / L-TAE [B, T, 128, H/8, W/8]
Replaces raw Stage-3 feature map with hybrid DINOv3-fused tensor z(t) right before Temporal Attention.
Gram Anchoring Loss (w = 1.0) L_gram
MSE between current ViT patch Gram matrix and frozen epoch-5 Teacher snapshot. Preserves spatial geometry.
KoLeo Regularizer (w = 0.0) L_koleo
Negative log-distance to nearest neighbor sample. Spreads global wildfire representations in batch.
DINOv3 operates entirely as an auxiliary feature provider. Training initializes identically to original UTAE via zero-initialized gating.
